# Final figure and table selection

Use the figures and tables in this order after introducing Flat and Cache topology and the measurement protocol. The principal notebook renders all six figures and three tables. Each figure is exported as SVG and PNG. Figure values and placement categories use the named campaign records. Relative comparisons use the same quantity and scope.

| ID | Scientific purpose and final caption | Evidence and generation path |
| --- | --- | --- |
| **F1** | **Local Flat read bandwidth and core frequency.** Useful read throughput (GB/s) and effective core frequency (GHz) against active physical cores on socket 0, with an 8 GiB working set per stream. Bars show within-launch standard deviation where sampled. DDR is near its measured plateau by 28 cores and HBM gains substantially from 28 to 56. | [SVG](../figures/00_master_analysis/memory_scaling.svg). `report.read_scaling`, `read_scaling_clock` and `plotting.memory_scaling_figure`. `flat-bandwidth2-20261011T230637Z`. |
| **F2** | **Power clipping and clock changes under streaming load.** Flat socket 0 package power (W), effective core frequency (solid, GHz) and CHA-derived uncore frequency (dotted, GHz) at 1, 14, 28 and 56 cores. Open markers identify power clipping in more than half of counted PCU cycles. HBM reads at 56 cores run at about 350 W and a lower uncore frequency. The figure describes the measured operating point. | [SVG](../figures/00_master_analysis/power_and_clocks.svg). `report.power_table` and `plotting.power_clock_figure`. `flat-ustreams-20261019T205225Z`, U1. Notebook 06 and STREAMGAP E6/E7c give the controlled comparisons. |
| **F3** | **Cache-mode lookup traffic, DDR fills and hit rate.** Socket 0, 56 cores, working sets 8–128 GiB. DDR fills are visible below that capacity, and this curve describes the recorded host state. | [SVG](../figures/00_master_analysis/cache_capacity.svg). `report.cache_capacity_table` and `plotting.cache_capacity_counters_figure`. `cache-ucapacity-20261031T192305Z`. | **F4** | **Flat memory locality across one and two sockets.** Left panel compares local and remote 56-thread streams, right panel a single 112-thread reader's first-touch and interleaved placements. Explicit locality nearly preserves that sum, while interleaving incurs the cross-socket penalty. | [SVG](../figures/00_master_analysis/placement.svg). `report.local_remote_table`, `span_reference` and `plotting.placement_figure`. `flat-remotehbm-20261012T215047Z`, `flat-bandwidth2-20261011T230637Z`, `flat-span-20261012T073217Z` and the isolated baselines in the policy. Notebook 03 adds concurrent pairs. |
| **F5** | **BF16 projection Roofline.** Plain BF16 oneDNN projection, 14336×4096, M = 1–4096, one Flat socket with 56 cores and a converged weight pool. The HBM/DDR advantage is largest at small M and decreases toward the library plateau. | [SVG](../figures/00_master_analysis/roofline_bf16.svg). `report.counted_gemm_frame`, `measured_memory_ceiling`, `compute_ceiling` and `plotting.roofline_figure`. `flat-ugemmconv-20261020T201733Z`, `flat-usweep-20261020T210357Z`, `flat-isa-20261011T225342Z`. |
| **F6** | **INT8 projection Roofline.** The corresponding prepacked INT8 oneDNN projection. Throughput counts each multiply and add as two integer operations and is shown in trillions of integer operations per second. The HBM points reach their empirical ridge at M = 256. The DDR points stay below their ridge through M = 4096. The HBM and DDR rates converge as reuse increases. | [SVG](../figures/00_master_analysis/roofline_int8.svg). Same code and campaigns as F5, with the INT8 tile reference. |
