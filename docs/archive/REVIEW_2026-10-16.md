# Scientific review — 2026-10-16

Second independent review of the hardware characterization, at commit `900da40` (`develop`).
Kept as the reference for the item IDs used in [STATUS.md](../STATUS.md); findings may be resolved
by later commits. Review only: no files changed and no cluster jobs run. `pytest` passed
(109 tests) and `check_artifacts.py` passed; every number was re-derived from
`data/processed/measurements.csv` through `hwbench.report`.

## Verdict

Compute and Flat-mode memory characterization are thesis-grade and need no more runs. What
remained was mostly analysis: the master notebook plotted GEMM data the repository had itself
shown to be biased, Cache-mode uncertainty was understated, and several statements were stale or
inconsistent. One short Flat GEMM run plus analysis edits closes the critical and high items.

## Correct and complete

* Compute peaks for six paths: 94–99% of the per-cycle peak at the measured clock; three launches
  within 0.25%; `EXE.AMX_BUSY` 98.8%; kernels with independent chains, exact checksums and a
  per-loop disassembly check.
* Flat bandwidth (read, Triad, NT Triad, copy), 1S/2S, core scaling with clock: seven Flat
  launches of HBM read give 538–554 GB/s, DDR Triad 234.8–235.0.
* Traffic model validated by per-core offcore-response counters (0.989–1.003; Triad read share
  0.664, no read-for-ownership). Ordinary copy compiles to a `ymm` loop, not `memcpy`.
* Dual-socket independence (0.984–1.017 over 29 pairs), span, remote-HBM repeat with thread sweep,
  12-chain FP64 sweep with copy ceiling, hierarchy after the L1 fix, the GEMM confound runs, the
  execution guards and the versioned data.

## Missing

  the read ceiling, implied Llama-3.1-8B tokens/s bound (HBM beats DDR by 1.43–1.55× for the GEMM,
  not 2.07×).
* **M2** Between-campaign uncertainty (see C2).
* **M3** Comparison with published STREAM results for the 9480 in the same clustering mode.
* **R1** Flat run: 14336×4096, M = 1…256, pool ≥ 16×, HBM and DDR, BF16 plain and prepacked, INT8,
  counters on. Acceptance: counted/modeled 0.97–1.03 at M ≤ 16; no point above its read ceiling.
* **R2** (optional) Flat DDR pointer chase at 16–128 GiB as the translation control for C7.
* **R3** (optional) Loaded latency: one chasing core while N cores stream HBM.
