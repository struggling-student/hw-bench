# Reading order

0. [Master analysis](00_master_analysis.ipynb): the six principal figures and three summary tables
1. [Platform and methodology](01_platform_and_methodology.ipynb): platform record, execution rules, validity, repeatability
2. [Memory hierarchy and bandwidth](02_memory_hierarchy_and_bandwidth.ipynb): L1/L2/LLC/memory bandwidth and latency, Triad/read/non-temporal, Cache capacity
3. [NUMA and socket scaling](03_numa_and_socket_scaling.ipynb): local/remote, two-socket efficiency, a process spanning both sockets
4. [Compute throughput](04_compute_throughput.ipynb): per-path peaks, effective clock, GEMM shape sensitivity
5. [Roofline atlas](05_roofline_atlas.ipynb): empirical references, attained points and reference-crossing audit
6. [Memory controllers, power and clocks](06_uncore_power_and_clocks.ipynb): controller counters on the Flat and Cache nodes for controller bytes against the traffic model, power limit and clock drop, the fast first HBM window, energy, the data-pattern effect, remote memory, GEMM traffic and loaded concurrency
7. [Bandwidth configuration for inference](07_bandwidth_configuration.ipynb): socket-local HBM versus DDR/core splits, asymmetric dual-socket allocations, capacity and complete-shard scan bounds; completed November study, with archived acceptance and ranking

Each notebook runs independently from a clean kernel after `bash scripts/make_analysis.sh` builds and validates local data. The notebook sources are generated by `scripts/build_notebooks.py`; notebook 07's source is in `scripts/bandwidth_search_notebook.py`, imported by the builder. Edit these sources, not the `.ipynb`. Shared transformations live in `hwbench.report` and `hwbench.analysis`, ceilings in `hwbench.roofline`, theory in `configs/theory.toml`. Each figure cell exports its displayed Plotly object as SVG and PNG. Do not edit generated images or derived CSVs by hand.
