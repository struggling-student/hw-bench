# Reading order

0. [Master analysis](00_master_analysis.ipynb): the findings, with the supporting detail linked
1. [Platform and methodology](01_platform_and_methodology.ipynb): platform record, execution rules, validity, repeatability
2. [Memory hierarchy and bandwidth](02_memory_hierarchy_and_bandwidth.ipynb): L1/L2/LLC/memory bandwidth and latency, Triad/read/non-temporal, Cache capacity
3. [NUMA and socket scaling](03_numa_and_socket_scaling.ipynb): local/remote, two-socket efficiency, a process spanning both sockets
4. [Compute throughput](04_compute_throughput.ipynb): per-path peaks, effective clock, GEMM shape sensitivity
5. [Roofline atlas](05_roofline_atlas.ipynb): every precision × memory configuration × socket scope, with achieved points

Each notebook runs independently from a clean kernel after `bash scripts/make_analysis.sh` builds and validates local data. The notebook sources are generated by `scripts/build_notebooks.py`; edit that file, not the `.ipynb`. Shared transformations live in `hwbench.report` and `hwbench.analysis`, ceilings in `hwbench.roofline`, theory in `configs/theory.toml`. Each figure cell exports its displayed Plotly object as SVG and PNG. Do not edit generated images or derived CSVs by hand.
